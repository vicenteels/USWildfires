# US Wildfires Analysis (1992–2015)

Exploratory Data Analysis (EDA) of the US Wildfires dataset using SQL and Pandas.

This project investigates wildfire occurrence patterns across the United States between 1992 and 2015, focusing on wildfire frequency, causes, size distribution, seasonality, and containment times.

---

## Dataset

**Source:** Kaggle - US Wildfires Dataset

The dataset contains approximately 1.88 million wildfire records collected from federal, state, and local reporting systems.

Main fields analyzed:

- Fire discovery date
- Fire containment date
- Fire size
- Fire cause
- State and county information
- Geographic coordinates

## Questions Explored

### 1. Which states experienced the highest number of wildfires?

### 2. What are the most common wildfire causes?

### 3. What are the largest recorded wildfires?

### 4. What percentage of fires are caused by each ignition source?

### 5. How has wildfire frequency changed over time?

### 6. Which months have the highest wildfire occurrence?

### 7. How many wildfires exceeded 5,000 acres?

### 8. Which columns contain the most missing values?

### 9. Which states take the longest time to contain wildfires?
